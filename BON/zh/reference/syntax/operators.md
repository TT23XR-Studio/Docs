# 运算符

## 算术运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+` | 加法 / 字符串拼接 / 数组合并 | `1 + 2` → `3`, `"a" + "b"` → `"ab"` |
| `-` | 减法 | `5 - 3` → `2` |
| `*` | 乘法 | `4 * 5` → `20` |
| `/` | 除法 | `10 / 2` → `5` |
| `%` | 取模 | `10 % 3` → `1` |

## 比较运算符

| 运算符 | 说明 |
|--------|------|
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

## 一元运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `-` | 取负 | `-5` → `-5` |

## 运算规则

- `number + number` → 数学加法
- `string + string` → 字符串拼接
- `array + array` → 数组合并
- 其他类型组合会报 `TypeError`

## 示例

```bon
{
    "sum": 10 + 20,           // 30
    "product": 4 * 5,         // 20
    "greeting": "Hi, " + "BON", // "Hi, BON"
    "items": [1] + [2, 3],    // [1, 2, 3]
    "is_valid": 5 > 3         // true
}
```
